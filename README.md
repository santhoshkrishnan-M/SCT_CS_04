# SCT_CS_04 - Keyboard Activity Monitor

## Task Description

Develop a keyboard activity monitoring tool that captures keyboard input within the application and logs the entered text to a file.

## Objective

The objective of this project is to understand keyboard event handling, input logging concepts, and file operations using Python.

## Features

* Captures keyboard input within the application
* Displays key presses in real time
* Logs entered text to a file
* Simple and easy-to-use interface
* Demonstrates keyboard event monitoring concepts

## Technologies Used

* Python
* pynput

## How to Run

1. Clone the repository.
2. Open a terminal in the project folder.
3. Install the required package:

```bash
pip install pynput
```

4. Run the program:

```bash
python SCT_CS_04.py
```
